# Compartir tu CV por link

Ya tienes una versión estática lista en:

- `docs/cv/index.html`

## Opción recomendada: GitHub Pages

Si activas GitHub Pages usando la carpeta `docs`, tu link quedará así:

- `https://gdonovarros-eng.github.io/holoacademia-ai/cv/`

Pasos:

1. Sube estos cambios a GitHub.
2. En tu repositorio, entra a `Settings > Pages`.
3. En `Build and deployment`, elige:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/docs`
4. Guarda.
5. Espera a que GitHub publique el sitio.

## Opción alternativa: Netlify

También puedes publicar solo la carpeta `docs/cv` en Netlify con drag and drop.

## Archivos que puedes editar

- `docs/cv/index.html`
- `docs/cv/cv.css`
- `docs/cv/cv.js`
