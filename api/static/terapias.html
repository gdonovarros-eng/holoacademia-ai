Preparación general antes del rastreo

Antes de iniciar cualquier rastreo, tanto el operador como el consultante deben estar en estado óptimo. La calidad del rastreo depende de la presencia plena y la claridad del operador.

Cómo se usa cada tabla específicamente

Cada sistema (Homeopatía, Bach, Schüssler) tiene una tabla con estructura propia (sectores, lados, números). Aquí se explica cuándo usar cada tabla, su estructura, cómo navegarla y un ejemplo concreto de navegación.
