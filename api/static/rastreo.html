Rastreo de Imanes

¿Cómo realizar el Rastreo de Imanes? ▼
  1. Identifica la Región Corporal con sintomatología o bajo estudio
  2. Selecciónala en el mapa anatómico — resalta la zona al pasar el cursor
  3. Navega: Mapa Anatómico → Zona de Rastreo → Par Biomagnético
  4. Confirma el par y agrégalo a la sesión activa
  5. Al finalizar, genera el mapa de colocación de imanes para el paciente
